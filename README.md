This entry explains a toaster to a 10-year-old in exactly two lines, built on one concrete analogy: a toaster is a tiny elevator for bread. The bread rides down into the heat, gets toasted, and pops back up ready to eat — no jargon, just the elevator ride.

## Run it

```sh
python3 main.py
```

This writes exactly two lines to `/output/entry.txt`. Override the output location with the `OUTPUT_PATH` environment variable:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```

The output is byte-identical on every run: deterministic, offline, and stdlib-only.
